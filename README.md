# CarFriendly — Working Name, Not Launched
Car Buying, The Friendly Way. No Tyrekickers. Only Real Buyers.

## Core only — Launch with this
Listings, Account Gate, Offer Gate, Slots, Slot Fee, Escrow flow (test mode), £1/day billing (test), 20 photos + 1 video, Filters, My Garage (basic)

## Bolt-ons — Switched OFF until launch
See config/flags.ts — finance, insurance, breakdown, warranty, private-reg, parts, MOT are OFF by default.

## Run
1. Install Node.js v26.13.1 LTS
2. npm install
3. cp .env.example .env.local  (add Supabase keys)
4. npm run dev -> http://localhost:3000
